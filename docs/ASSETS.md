# Benchmark assets

Large downloaded files, portable Blender, generated exports, and renders live under the ignored `build/` directory. Source scripts and this provenance record are versioned. Downloads use fixed URLs and SHA-256 verification; checksum mismatches fail instead of accepting a changed asset.

```sh
python3 scripts/scene_assets.py --list
python3 scripts/scene_assets.py blender classroom sponza studio_hdri
```

The default invocation downloads all assets. Sponza alone is a 3.99 GB archive and expands to several GB. `--directory` and `--tools-directory` select other cache locations. The setup script writes a provenance JSON next to each extracted asset and verifies cached archives on repeat runs.

The material-studio fixture and its checker, roughness and tangent-normal maps are generated by `scripts/create_blender_fixture.py`; no external models or textures are required.

## Paths after setup

- Portable Blender: `build/tools/blender-4.5.3-linux-x64/blender`.
- Classroom source: `build/assets/classroom/classroom/classroom.blend`; preserve sibling asset libraries and textures.
- Intel Sponza glTF: `build/assets/sponza/main_sponza/NewSponza_Main_glTF_003.gltf`; preserve its `.bin` and `textures/`.
- Studio HDRI: `build/assets/studio_hdri/studio_small_09_1k.hdr`.

See [Blender import](BLENDER_IMPORT.md) for generated comparison-source commands. A downloaded scene is not automatically a supported Xenon scene: strict export reports material, lighting, and camera limitations before writing a usable `.xenon` file.

## Blendkit gallery scenes

The Blendkit imports use separately downloaded originals under `build/assets/blendkit/`. [blendkit-assets.json](blendkit-assets.json) records their asset/version IDs, source checksums, authors and license metadata. The original `.blend` files and their textures are not redistributed in this repository.

| Scene | Author | Local directory |
|---|---|---|

| [Forgotten Industrial Warehouse](https://www.blendkit.com/asset-gallery-detail/9cb181dc-d05a-42c0-880c-5949918ce392/) | Ibrohim Toxirov | `warehouse` |

All three downloads reported Blender 5.2 and Blendkit's `royalty_free` license. The public API supplies the current asset version, rather than an immutable download URL. Use `download_blendkit.py --sha256 HASH` with the recorded checksum when reproducing these exact originals; a changed version fails verification. Local checksums identify the files we used, rather than serving as an upstream signature.
